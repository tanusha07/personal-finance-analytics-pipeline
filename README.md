# Personal Finance Analytics Pipeline

An end-to-end data engineering and analytics project that builds a personal finance tracker on **synthetic data**: it generates fake transactions, loads and cleans them in PostgreSQL on a daily schedule, flags unusual spending with machine learning, forecasts the next 30 days, and serves the results through an API and a Power BI KPI dashboard.

> All data is randomly generated by `generate_data.py`. No real bank or personal data is used.

## Architecture

```
generate_data.py -> load_to_postgres.py -> clean_data.py      (Airflow DAG, runs daily in Docker)
                                              |
                         +--------------------+--------------------+
                         |                                         |
               anomaly_detection.py                         forecasting.py
          (Isolation Forest -> flagged_anomalies)   (Prophet -> spending_forecast)
                         |                                         |
                         +--------------------+--------------------+
                                              |
                          FastAPI (/summary, /anomalies, /forecast, /kpis)
                                              |
                                   Power BI KPI dashboard
```

## Tech stack

Python, PostgreSQL 16, Docker, Apache Airflow, pandas, scikit-learn (Isolation Forest), Prophet, FastAPI, Power BI, pytest.

## What it does

- **Orchestration:** an Airflow DAG (`expense_tracker_pipeline`, `@daily`) runs generate -> load -> clean inside Docker.
- **Idempotent loads:** each load truncates its table first, so re-running never creates duplicate rows. (This fixed a real bug where repeated runs inflated the data from 437 to over 400,000 rows.)
- **Anomaly detection:** Isolation Forest on expense amounts flags unusual transactions into `flagged_anomalies`.
- **Forecasting:** Prophet predicts daily spending for the next 30 days into `spending_forecast`.
- **API:** FastAPI endpoints for transactions, summary, anomalies, forecast and headline KPIs.
- **Dashboard:** a Power BI KPI page (income, expenses, net savings, savings rate, average daily spend, top category, anomalies, 30-day forecast). Setup steps and DAX measures are in [`powerbi/kpi_measures.md`](powerbi/kpi_measures.md).

## Run it locally

```bash
# 1. Start PostgreSQL
docker compose up -d

# 2. Install dependencies
pip install -r requirements.txt

# 3. Run the pipeline steps
python generate_data.py
python load_to_postgres.py
python clean_data.py
python anomaly_detection.py
python forecasting.py

# 4. Start the API  ->  http://localhost:8000/docs
uvicorn api:app --reload
```

To run the daily schedule with Airflow, use the compose file in `airflow/` (create `airflow/.env` with your own `FERNET_KEY`).

Database settings default to the local demo values in `docker-compose.yml`; override them with `DB_HOST`, `DB_PORT`, `DB_NAME`, `DB_USER` and `DB_PASSWORD`.

## Tests

```bash
pip install -r requirements-dev.txt
pytest
```

The tests cover data generation, cleaning, anomaly detection, forecasting, the API endpoints, and a regression test for the duplicate-load bug. They need no running database.
